Build your own keymap configuration. Add entries, record shortcuts by pressing keys, and the result is persisted locally via the [Origin Private File System](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API/Origin_private_file_system). Expand the JSON output at the bottom to copy your config.
