## Shortcut Layers

Press <Kbd client:only="solid-js" combo="mod+k" /> and follow the keys. Each layer you open takes
over the keyboard until <kbd>Esc</kbd> drops you back to the one beneath it.

  <Card title="Safe by default" icon="approve-check">
    Matches on `key`, not `code` — only a-z and 0-9 are allowed as non-modifier keys. Shift+digit is
    rejected to avoid locale-dependent behavior. The `mod2` keyword provides a safe cross-platform
    secondary modifier (Ctrl on macOS, Alt on Windows/Linux).
  </Card>
  <Card title="Key sequences" icon="list-format">
    Multi-chord shortcuts like <Kbd client:only="solid-js" combo="mod+k mod+c" /> with configurable
    timeouts between chords.
  </Card>
  <Card title="Held-keys tracking" icon="puzzle">
    Real-time tracking of pressed keys with stale-modifier recovery, blur reset, and single-key hold
    detection.
  </Card>
  <Card title="Shortcut recording" icon="setting">
    Built-in `recordShortcut()` utility for "press a key to rebind" UIs with safety validation.
  </Card>
